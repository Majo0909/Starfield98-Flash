# Space Starfield 98

Portable browser version of the classic Windows 95/98 **Starfield Simulation** — flying through a field of stars.

## Spustenie

Dvojklik na `index.html`. Pre skutočný screensaver-like režim stlač `F11`.

## Ovládanie

- `F11` — celá obrazovka
- `P` — pauza / pokračovať
- `S` — panel nastavení
- `Esc` — skryť panel
- pohyb myšou — jemné vychýlenie smeru

## Poznámka

Projekt je zámerne bez závislostí a bez build kroku, aby fungoval okamžite aj offline.
